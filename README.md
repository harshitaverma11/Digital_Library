# 📚 Digital Library System

A modern and responsive **Digital Library Web Application** built using **HTML, CSS, and JavaScript**. This project allows users to browse books, search, and manage issued books with data stored in LocalStorage.

---

## 🚀 Features

* 🔍 Search books by title
* 📖 Browse available books
* 📥 Issue books
* 🔄 Return books
* 👤 User dashboard (Issued books view)
* 🌙 Dark mode support
* 📱 Fully responsive design (Mobile + Tablet + Desktop)

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & responsiveness
* **JavaScript** – Functionality
* **LocalStorage** – Data persistence

## ⚙️ How to Run the Project

1. Download or clone the repository
2. Open `index.html` in your browser
3. Start exploring the Digital Library

---

## 🎯 Project Objective

The goal of this project is to build a fully functional frontend application using **core web technologies** without any frameworks, while implementing real-world features like search, state management, and responsive UI.
